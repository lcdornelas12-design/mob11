🚀 O Fluxo Profissional: Por que usar VS Code + GitHub Pages?

Diferente de um site tradicional que roda apenas no navegador, um PWA exige conexão segura HTTPS para que o Android ou iOS autorizem o registro do Service Worker e o botão de instalação na tela inicial. O GitHub Pages resolve isso gratuitamente em segundos!

1

Codificar no VS Code

Organize seus 3 arquivos: index.html, manifest.json e sw.js na mesma pasta.

2

Subir para o GitHub

Envie sua pasta para um repositório público (via extensão Git do VS Code ou arrastando no site do GitHub).

3

Ativar o Pages

Em Settings ➔ Pages, ative a branch main e obtenha seu link com HTTPS grátis.

4

Instalar no Celular

Abra o link no Chrome do celular, toque nos 3 pontinhos e clique em "Instalar Aplicativo"!

💡 Dica de Ouro no VS Code: Use a extensão Live Server para testar no computador antes de subir para o GitHub Pages. O Live Server roda em http://localhost:5500, que é considerado um ambiente seguro pelo navegador para testes com Service Worker.

📄 A Identidade do App: manifest.json

O arquivo manifest.json transforma uma aba de navegador em um ícone de aplicativo. Ele configura a cor da barra de status, o ícone de abertura e remove a barra de URL com a instrução "display": "standalone".

📂 No VS Code: Crie um novo arquivo com o nome exato manifest.json na raiz do projeto e cole o código completo abaixo:
📄 manifest.json (Completo & Sem Omissões) 
{
  "name": "LojaExpress Pro Delivery",
  "short_name": "LojaExpress",
  "description": "App de pedidos, catálogo de lanches e ERP administrativo",
  "start_url": "./index.html",
  "display": "standalone",
  "background_color": "#0f172a",
  "theme_color": "#4f46e5",
  "orientation": "portrait",
  "icons": [
    {
      "src": "https://cdn-icons-png.flaticon.com/512/3081/3081840.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "https://cdn-icons-png.flaticon.com/512/3081/3081840.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}

🔗 Como o HTML descobre o Manifest?

Adicione estas duas linhas dentro da tag <head> do seu index.html:

📄 Inserir no <head> do index.html 
<!-- Conexão do PWA com o Manifest -->
<link rel="manifest" href="manifest.json">
<meta name="theme-color" content="#4f46e5">

⚙️ O Motor do PWA: sw.js (Service Worker)

O Service Worker é um script que o navegador executa em segundo plano, separado da página web. Ele funciona como um "guarda de trânsito": quando o cliente solicita um lanche ou abre a loja, o Service Worker intercepta o pedido e, caso o cliente esteja sem internet, entrega os arquivos salvos em cache!

📂 No VS Code: Crie um arquivo chamado sw.js na mesma pasta do seu projeto e cole o código completo abaixo:
📄 sw.js (Cache & Estratégia Offline Completa) 
const CACHE_NAME = 'lojaexpress-cache-v1';
const RECURSOS_ESSENCIAIS = [
  './',
  './index.html',
  './manifest.json',
  'https://cdn-icons-png.flaticon.com/512/3081/3081840.png'
];

// 1. Instalação: grava arquivos estáticos essenciais no Cache Storage
self.addEventListener('install', (evento) => {
  evento.waitUntil(
    caches.open(CACHE_NAME).then((cache) => {
      console.log('📦 [PWA] Armazenando arquivos vitais no cache...');
      return cache.addAll(RECURSOS_ESSENCIAIS);
    })
  );
  self.skipWaiting();
});

// 2. Ativação: limpa versões antigas de caches se o app atualizar
self.addEventListener('activate', (evento) => {
  evento.waitUntil(
    caches.keys().then((chaves) => {
      return Promise.all(
        chaves.map((chave) => {
          if (chave !== CACHE_NAME) {
            console.log('🧹 [PWA] Removendo cache obsoleto:', chave);
            return caches.delete(chave);
          }
        })
      );
    })
  );
  self.clients.claim();
});

// 3. Interceptação de Rede (Fetch): se não houver internet, responde do cache
self.addEventListener('fetch', (evento) => {
  evento.respondWith(
    caches.match(evento.request).then((respostaCache) => {
      // Retorna o cache se existir; senão tenta buscar na internet
      return respostaCache || fetch(evento.request).catch(() => {
        // Fallback defensivo para quando estiver 100% offline
        if (evento.request.destination === 'document') {
          return caches.match('./index.html');
        }
      });
    })
  );
});

🔗 Como Registrar o Service Worker no index.html?

Adicione este script logo antes do fechamento da tag </body>:

📄 Registro no final do index.html 
<script>
  // Registra o Service Worker assim que a página carregar
  if ('serviceWorker' in navigator) {
    window.addEventListener('load', () => {
      navigator.serviceWorker.register('./sw.js')
        .then((registro) => {
          console.log('✅ Service Worker Ativo! Escopo:', registro.scope);
        })
        .catch((erro) => {
          console.error('❌ Falha ao registrar Service Worker:', erro);
        });
    });
  }
</script>

Desafio: Adicione lanches ao carrinho, aplique o cupom e confira se o cálculo subtrai o total corretamente e se a compra é registrada com sucesso no LocalStorage.

Pergunta de Validação da Dinâmica 2:

🕹️ Dinâmica 3: "O Teste do Modo Avião no Celular"

Missão: Publique seu repositório no GitHub Pages. Abra a URL no smartphone via Chrome/Safari. Instale o app na tela inicial. Em seguida, ative o Modo Avião do celular (desligue Wi-Fi e 4G) e abra o aplicativo instalado!

Desafio: Comprove que a vitrine de lanches da LojaExpress abre instantaneamente, demonstrando o poder de resiliência de um PWA real.

📝 Avaliação de Programação Mobile: PWA & App de Pedidos

Esta avaliação consolida os conceitos aplicados na oficina: ciclo de interface, arquitetura de PWA, manipulação de dados locais e publicação no GitHub Pages.

🔀 PARTE 1 · Análise de Afirmativas V ou F (1,0 ponto cada)
Questão 1 — Tecnologias no App LojaExpress1,0 ponto

Analise as afirmativas sobre as responsabilidades das tecnologias no app de pedidos:

(I) O HTML estrutura os cards dos lanches, botões de adicionar e o modal do carrinho.

(II) O CSS garante o design responsivo móvel, o menu inferior fixo e as áreas de toque adequadas.

(III) O JavaScript é desnecessário em um PWA, pois o HTML calcula os totais do pedido automaticamente.

✅ Correto! Resposta: A

📖 Justificativa: I e II são verdadeiras. III é falsa porque o JS é o cérebro que calcula valores e comanda o Service Worker.

Questão 2 — Arquitetura PWA e Hospedagem1,0 ponto

Analise as afirmativas sobre Progressive Web Apps e GitHub Pages:

(I) O GitHub Pages fornece conexão HTTPS obrigatória para que o Service Worker funcione.

(II) Um PWA instalado a partir do GitHub Pages pode ser aberto pelo usuário mesmo sem conexão à internet.

(III) PWAs só funcionam em computadores desktop e são incompatíveis com smartphones Android e iOS.

✅ Correto! Resposta: B

📖 Justificativa: I e II são verdadeiras. III é falsa pois PWAs foram concebidos com foco prioritário em smartphones.

✅ PARTE 2 · Múltipla Escolha (1,0 ponto cada)
Questão 3 — Manipulação do DOM1,0 ponto

Quando o cliente clica em "Adicionar ao Pedido" e a quantidade do badge no ícone do carrinho salta de 0 para 1 em tempo real, qual mecanismo o JavaScript utilizou para atualizar a tela?

✅ Correto! Resposta: B

📖 Justificativa: O DOM permite ao JavaScript localizar e alterar conteúdos HTML dinamicamente sem recarregar a tela.

Questão 4 — Persistência com LocalStorage1,0 ponto

No protótipo da LojaExpress, para salvar a lista de pedidos e cupons no navegador, usamos o comando localStorage.setItem("db_pedidos", JSON.stringify(pedidos)). Para que serve o JSON.stringify?

✅ Correto! Resposta: A

📖 Justificativa: O LocalStorage só aceita dados em formato textual (String); JSON.stringify converte objetos em texto.

Questão 5 — O Papel do manifest.json1,0 ponto

Qual é a principal responsabilidade do arquivo manifest.json na transformação da loja em um aplicativo de celular?

✅ Correto! Resposta: B

📖 Justificativa: O manifest.json é a carteira de identidade do PWA, controlando ícone, nome e modo standalone.

Questão 6 — O Ciclo do Service Worker1,0 ponto

No arquivo sw.js, qual evento intercepta as buscas por arquivos e imagens, permitindo responder do cache quando o cliente está sem internet?

✅ Correto! Resposta: C

📖 Justificativa: O evento fetch intercepta todas as requisições de rede para responder arquivos a partir do Cache.

✍️ PARTE 3 · Questões Abertas Conceituais (1,0 ponto cada)
Questão 7 — Site Comum vs App PWA Instalado1,0 ponto

Explique a diferença de experiência para o usuário entre acessar a LojaExpress pelo navegador convencional e acessá-la como um PWA instalado na tela inicial.

💡 Sugestão de Resposta Esperada:
Como site comum, ele fica preso na aba com barra de URL. Como PWA instalado, ele ganha ícone na tela inicial, abre em tela cheia (standalone) e funciona mesmo sem internet.
Questão 8 — Persistência no App de Pedidos1,0 ponto

Por que o LocalStorage foi uma escolha vantajosa para persistir o estoque e os pedidos do protótipo LojaExpress durante esta oficina para iniciantes?

💡 Sugestão de Resposta Esperada:
Por ser simples, nativo do navegador e não exigir configuração de banco SQL ou servidores externos, permitindo salvar dados localmente no próprio aparelho do aluno.
Questão 9 — Resiliência Offline1,0 ponto

De que maneira o Service Worker garante que um entregador ou cliente continue vendo o cardápio mesmo se passar por uma área sem sinal de celular?

💡 Sugestão de Resposta Esperada:
O Service Worker armazena previamente os arquivos vitais (HTML, manifest, imagens) no Cache Storage e os entrega imediatamente quando a conexão falha.
Questão 10 — A Importância do GitHub Pages1,0 ponto

Por que a publicação no GitHub Pages (HTTPS) é um passo indispensável para o sucesso da instalação do aplicativo no smartphone real do aluno?

💡 Sugestão de Resposta Esperada:
O protocolo HTTPS é uma exigência obrigatória de segurança dos navegadores para liberar os recursos de Service Worker e o prompt de instalação no celular.
